このアプリについて

本アプリは、東証プライム市場の過去データを統計的に分析し、 「52週高値圏で、かつ過去の実績が良好だったパターン」に合致する銘柄を 毎日自動で抽出・表示するものです。

投資助言ではありません。 表示される情報はすべて過去の統計にもとづく参考情報であり、 将来の値動きを保証するものではありません。売買の最終判断は、 ご自身の責任で行ってください。

総合スコアの算出式

総合スコア = 期待値 + 業種調整 × 0.5 + チャートの締まり具合

  • 期待値: 「高値更新回数×直前の値上がり率」の12パターン別の過去の平均リターン。件数が少ないマスは全体平均へ寄せて補正済み
  • 業種調整: 業種ごとの過去の実績差。相場環境に依存する可能性があるため、影響は半分の重みに抑えている
  • チャートの締まり具合: 直前の値幅が狭い(タイトな)銘柄ほど加点

「注目」タブ(チャートの型)

上昇の後に「ベース(もみ合い)」を作っている銘柄を、次の3つの型で機械的に判定して表示します。 ピボット(ブレイクの目安価格)まで5%以内のものと、当日の終値でピボットを上抜けたものが対象です。

  • カップウィズハンドル: 12〜35%下げたU字のカップの後、上半分で小さく押した(取っ手)形。ピボットは取っ手の始まりの高値
  • フラットベース: 30%以上上昇した後、高値圏で値幅10%以内の横ばいが5週以上続き、出来高が細っている形。ピボットはベースの高値
  • VCP: 上昇トレンド中に、押し目が回を追うごとに浅くなる形(例: 17% → 9% → 5%)。ピボットは最後の押し目の高値

形の判定は計算式による機械的なもので、見落としや誤判定があります。 監視候補を探すための参考情報であり、売買を勧めるものではありません。

詳しい検証内容・売買時のチェック手順は、リポジトリ内の TRADING_RULE.md / HOW_TO_TRADE.md を 参照してください。
