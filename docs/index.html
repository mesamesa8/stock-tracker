このアプリについて

本アプリは、東証プライム市場の過去データを統計的に分析し、 「52週高値圏で、かつ過去の実績が良好だったパターン」に合致する銘柄を 毎日自動で抽出・表示するものです。

投資助言ではありません。 表示される情報はすべて過去の統計にもとづく参考情報であり、 将来の値動きを保証するものではありません。売買の最終判断は、 ご自身の責任で行ってください。

総合スコアの算出式

総合スコア = 期待値 + 業種調整 × 0.5 + チャートの締まり具合

  • 期待値: 「高値更新回数×直前の値上がり率」の12パターン別の過去の平均リターン。件数が少ないマスは全体平均へ寄せて補正済み
  • 業種調整: 業種ごとの過去の実績差。相場環境に依存する可能性があるため、影響は半分の重みに抑えている
  • チャートの締まり具合: 直前の値幅が狭い(タイトな)銘柄ほど加点

「注目」タブ(チャートの型)

上昇の後に「ベース(もみ合い)」を作っている銘柄を、次の3つの型で機械的に判定して表示します。 ピボット(ブレイクの目安価格)まで5%以内のものと、当日の終値でピボットを上抜けたものが対象です。 「判定日」で過去60営業日分の結果も選べます。過去の日付では、その日までのデータだけで判定した結果に、 その後の値動き(チャートの色の変わった部分・騰落率・ピボットを上抜けたか)を重ねて表示します。

  • カップウィズハンドル: 30%以上上昇した後、12〜33%下げて3〜6ヶ月かけて戻したカップ(底では出来高が減少)に、5〜10%押した取っ手(5〜25営業日、10週線より上、出来高減少)が付いた形。ピボットは取っ手の高値で、ブレイクは終値がピボットを超え、出来高が直前50営業日平均の1.4倍以上の日。この型はピボットまでの距離で絞り込まない
  • フラットベース: 30%以上上昇した後、高値圏で値幅10%以内の横ばいが5週以上続き、出来高が細っている形。ピボットはベースの高値
  • VCP: 上昇トレンド中に、押し目が回を追うごとに浅くなる形(例: 17% → 9% → 5%)。ピボットは最後の押し目の高値

決算(前年同期比)と「ピックアップ」タブ

注目タブの各銘柄に、最新の決算短信の直近四半期(3ヶ月)の売上高・営業利益の前年同期比を表示します。 決算データはJ-Quants(無料版)から取得しているため約12週間遅れで、表示している決算の発表日を併記しています。 前年の営業利益が赤字の場合は増益率を計算できないため「黒字転換」と表示します(ピックアップの条件には含めません)。

「ピックアップ」タブには、直近2週間(10営業日)に注目タブに出た銘柄のうち、 最新の決算が売上高+10%以上・営業利益+20%以上(前年同期比)の銘柄を表示します。

形の判定は計算式による機械的なもので、見落としや誤判定があります。 監視候補を探すための参考情報であり、売買を勧めるものではありません。

詳しい検証内容・売買時のチェック手順は、リポジトリ内の TRADING_RULE.md / HOW_TO_TRADE.md を 参照してください。
